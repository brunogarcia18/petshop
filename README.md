# PetShop Amigo Fiel - Fase 1

Sistema web para um petshop, desenvolvido como Fase 1 do Projeto da Disciplina.

## Sobre esta fase

Nesta fase, o site foi construído **somente com HTML**, sem customizações de CSS/Bootstrap
e sem funções em JavaScript (essas partes serão desenvolvidas na Fase 2 do projeto).

## Páginas do site

| Página | Arquivo | Descrição |
|---|---|---|
| Início | `index.html` | Apresentação do petshop, contato e horário de funcionamento |
| Produtos | `produtos.html` | Dois produtos de cada uma das 3 categorias (Alimentação, Higiene e Beleza, Brinquedos e Acessórios), com foto, descrição e valor |
| Serviços | `servicos.html` | Serviços oferecidos (descrição, valor e indicação de tele-busca) |
| Ajuda | `ajuda.html` | Explicação das funcionalidades do site |

## Estrutura de cada página

- **Cabeçalho (header):** nome/identificação do petshop, informações de contato e menu de navegação.
- **Corpo (body/main):** conteúdo específico de cada página (produtos ou serviços).
- **Rodapé (footer):** informações legais/autoria, contato e links de navegação.
