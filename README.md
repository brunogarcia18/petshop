# PetShop Amigo Fiel - Fase 1

Sistema web desenvolvido para um petshop utilizando apenas HTML.

## Páginas

- `index.html` - Página inicial
- `produtos.html` - Produtos do petshop
- `servicos.html` - Serviços oferecidos
- `ajuda.html` - Informações sobre o site

## Estrutura

Todas as páginas possuem:

- Cabeçalho (header)
- Conteúdo principal (body/main)
- Rodapé (footer)

## Funcionalidades

- Exibição de produtos com imagem, descrição e valor.
- Exibição de serviços com descrição, valor e informação sobre tele-busca.
- Navegação entre as páginas do sistema.

## Tecnologias Utilizadas

- HTML5
